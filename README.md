# 🎓 Student Support Analytics Dashboard

> 📊 An interactive Excel dashboard to analyze student support tickets, agent performance, resolution time, ticket status, and satisfaction levels.

---

## 📌 About The Project

The **Student Support Analytics Dashboard** is an interactive Excel-based analytics project designed to help support teams monitor and understand ticket performance.

The dashboard provides a centralized view of:

- 🎫 Total support tickets
- 👩‍💻 Support agent performance
- 📂 Ticket categories
- 🚦 Ticket priorities
- 📌 Ticket status
- ⏱️ Resolution time
- ⭐ Student satisfaction

The dashboard allows users to filter the analysis by **Support Agent** and dynamically view agent-specific performance.

---

## 🎯 Project Objective

The main objective of this project is to create an interactive dashboard that helps answer questions such as:

- 👤 How many tickets did each support agent handle?
- ✅ How many tickets were resolved?
- ⏳ How many tickets are still pending or in progress?
- 📂 Which categories generate the most tickets?
- 🚦 How are tickets distributed across priority levels?
- ⏱️ What is the average resolution time?
- ⭐ What is the average satisfaction score?
- 📊 How does an individual agent's performance vary across categories?

---

## 🗂️ Dataset

The dataset contains fictional student support ticket records created for learning and portfolio purposes.

### 📋 Key Columns

| Column | Description |
|---|---|
| 🎫 Ticket ID | Unique identifier for each ticket |
| 📅 Date | Date when the ticket was created |
| 👨‍🎓 Student | Student associated with the ticket |
| 👩‍💻 Support Agent | Agent handling the ticket |
| 📂 Category | Type of support request |
| 🚦 Priority | Ticket priority level |
| 📌 Status | Current ticket status |
| ⏱️ Resolution Time | Time taken to resolve the ticket |
| ⭐ Satisfaction | Student satisfaction score |

## 📊 Dashboard Components

### 1️⃣ Support Agent Performance Summary

Provides an overview of the selected agent's:

- 🎫 Total Tickets
- ⏱️ Average Resolution Time
- ⭐ Average Satisfaction

---

### 2️⃣ 🍩 Ticket Status Distribution

A donut chart showing the distribution of tickets across:

- ✅ Resolved
- ⏳ Pending
- 🔄 In Progress
- 🚨 Escalated

---

### 3️⃣ 📊 Tickets by Category & Priority

Shows the distribution of support tickets across different categories and priority levels.

This helps identify:

- 📂 High-volume categories
- 🚦 Priority patterns
- 🔎 Areas requiring further analysis

---

### 4️⃣ 📈 Category-wise Resolution Time & Satisfaction

Compares:

- ⏱️ Average Resolution Time
- ⭐ Average Satisfaction

across different support categories.

This helps understand how different types of support requests are performing.

---

## 🎛️ Interactive Analysis

The dashboard includes a **Support Agent filter/slicer** that allows users to analyze the performance of individual support agents.

By selecting a specific agent, the dashboard dynamically updates the analysis to show:

- 🎫 Total tickets handled
- ✅ Resolved tickets
- ⏳ Pending tickets
- 🔄 In-progress tickets
- 🚨 Escalated tickets
- 📂 Tickets by category
- ⏱️ Average resolution time
- ⭐ Average satisfaction score

This makes it easier to understand an individual agent's workload, resolution patterns, and satisfaction performance.
